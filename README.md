## ⚡ Overview
**Media Yantra** is an ultra-fast, robust, and aesthetically minimalist desktop application designed exclusively for seamless high-fidelity media extraction. Engineered with concurrent multi-threaded download pipelines, this tool drastically accelerates data processing, allowing you to pull high-quality videos and lossless audio arrays natively without relying on heavy or restrictive web intermediaries. 

It serves as a professional-grade extraction suite featuring an incredibly clean, responsive dark-mode graphical wrapper heavily optimized for zero bloatware and an intuitive user experience.

---

## 🚀 Key Features

| Feature | Description |
| :--- | :--- |
| **🏎️ Blazing-Fast Engine** | Utilizes split-second, multi-threaded pipelines and chunked downloading to pull gigabytes of data at maximum bandwidth limits. |
| **🎨 Premium Aesthetic UI** | A sleek dark-mode graphical wrapper crafted with `CustomTkinter`, optimized for zero bloat and absolute usability. |
| **🎧 Lossless Audio Processing** | Rip crystal-clear audio streams natively (MP3, WAV, FLAC, OGG) at maximum 320kbps encoding. |
| **📚 Automated Playlists** | Feed massive playlist links and let the engine asynchronously map out huge queues without requiring manual monitoring. |
| **🏷️ Custom Metadata Tagging** | Securely writes ID3 metadata arrays and naturally embeds high-resolution cover arts dynamically inside your generated audio files. |
| **🛡️ Unbreakable Extraction** | Built with sequential API engines (`yt-dlp` and fallback parameters) ensuring completely unbreakable link extractions. |
| **📦 Offline Dependency Engine**| Formally bundled with internal `FFmpeg` packages, requiring explicitly zero external third-party software to function out-of-the-box. |
| **🕒 Built-in History View** | Keeps track of all your downloads dynamically in a beautifully responsive History grid layout, allowing easy access to folders. |

## 🛠️ Tech Stack

- **Core**: `Python 3.10+`
- **UI Framework**: `CustomTkinter`
- **Extraction Engine**: `yt-dlp`
- **Media Processing**: `FFmpeg`
- **Metadata**: `mutagen`
- **Image Processing**: `Pillow`

## 💾 Installation

### Option 1: Native Windows Installer (Recommended)
1. Go to the **Releases** tab on GitHub.
2. Download `Media_Yantra_Setup.exe`.
3. Run the straightforward wizard to instantly install the software.
4. Access Media Yantra directly from your Desktop!

### Option 2: Run from Source
If you want to run the project from source or contribute:

```bash
# Clone the repository
git clone https://github.com/The-Kartik-Kothalkar/MediaYantra.git

# Navigate to the project directory
cd MediaYantra

# Install required dependencies
pip install -r requirements.txt

# Run the application
python main.py
```
